## Purpose / Big Picture

The measured medical q11 currently uses a semantic projection boundary with separately native leaves under twelve OPTIONAL composites. The remaining adaptive invocation lifecycle dominates the accepted CPU/allocation profile. The goal is to enable one native value execution scope over a proved component without changing its final result, authority, receipts or ordinary operator behavior. Matched V2.1 measurements are available as directional one-fork, zero-warmup evidence, not as a general performance claim.

A LOCAL flag is a producer event, independent of mapping presence. V2 incorrectly assumed successful normalized BGP declarations could be unioned as an exact full-row origin under canonical empty input. Hash/merge and memoized OPTIONAL copy only selected/written metadata, so hidden flags can differ from lexical evaluation. A full-row composite capability is withdrawn. The narrower candidate is confined to an actual closing Projection: only information that this exact projection observes may be represented privately, and its complete final row is published only after projection. All unproved inputs, scopes and consumers retain existing semantic preparation before input consumption.
