## Purpose / Big Picture

Use the supplied paper and reference Java implementation to improve RDF4J join-order search while preserving RDF query results, binding dependencies, graph scopes, physical cost units, and bounded resource use. A join graph describes which relations can legally join. A connected split partitions a relation set into two adjacent connected child sets; enumerating useful splits directly can avoid exploring exponentially many invalid subsets. The paper's special double-star optimality theorem assumes positive multiplicative cardinalities and summed intermediate-row costs, which differ from RDF4J's contextual physical costing. Any implemented improvement must fit the current cost/session/continuation abstractions rather than replace them with the reference model.
