RDF4J 6.1.0 is a patch release that fixes 8 bugs.

This release does not include any new features and should be considered a patch release. It has been given a minor version bump to 6.1.0 because of a small binary incompatible breaking change that was required to fix [GH-6020](https://github.com/eclipse-rdf4j/rdf4j/issues/6020) which could cause deadlock during class initialization. 

We recommend everyone update to this version as it fixes a bug that could cause dataloss in LMDB.

For a complete overview, see [all issues fixed in 6.1.0](https://github.com/eclipse/rdf4j/milestone/131?closed=1).
