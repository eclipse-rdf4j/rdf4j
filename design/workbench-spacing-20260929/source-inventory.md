# RDF4J Workbench spacing audit: source inventory

**Purpose.** Source-derived coverage denominator for the spacing/alignment audit and browser pass. This file inventories the registered page renderers, branches and state transitions, and the stylesheet rules that own their geometry. The current source snapshot includes the final uncommitted shared patch: source mapping records its semantic structure, while observed RED and final verification are stated separately in `audit.md` and `browser-audit.md`. Source alone is not a pixel verdict.

**Scope and write boundary.** Read-only inspection of routing, page-model renderers, query result renderers, repository template sources, E2E/test fixtures, and loaded stylesheets. No production or test files changed. The only output owned by this worker is this inventory.

## Routing and denominator

`WorkbenchViewRegistry` has 20 servlet-class mappings that yield 19 distinct view IDs (`server` is shared by the gateway and servlet); **17 are navigable page renderer IDs** and `routeBody` confirms all 17 plus one fallback. `info` and `namespace-metadata` are registered as non-navigable service views; neither is a rendered route page. The `/info` route is used internally for repository existence/configuration checks. The namespace metadata servlet is `/repositories/{id}/_internal/namespaces`. `QueryServlet` omits a page view for any request with an `action` parameter or a nonblank query, and `get` / `explain` bypass the HTML shell. Do not count those native/streamed responses as extra page routes. ### Query and streamed-result closure

`queryStream.ts` renders three result families chosen by Java `QueryEvaluator`: `query-result-tuple`, `query-result-graph`, `query-result-boolean` (`QueryEvaluator.java:689,703,719`; `queryStream.ts:190-192`). A single result renderer also has error/no-result/loading and streamed/populated states. For tuple and graph results reveal both dynamic panels: `.query-result-download-toggle` (Format, Limit, Download) and `.query-result-options-toggle` (Layout Auto/Table/Records, Page size All/10/50/100/200 or server-requested value, Wrap values, Show datatypes). Exercise Previous page/Next page/Cancel query, record-layout Previous/Next, fullscreen, result totals, long cells, typed/language values, table horizontal scroll, and error state. For boolean, verify Yes/No and the expected absent/hidden row controls. Features in Workbench `queryFeatures` can hide controls; the default-enabled configuration is the complete action set. Saved-query executions mount the same result renderer with an instance suffix, so repeat reveals there, not just in the main query page. Sources: [`QueryEvaluator.java`](../../tools/workbench/src/main/java/org/eclipse/rdf4j/workbench/util/QueryEvaluator.java#L689), [`queryStream.ts`](../../tools/workbench/src/main/webapp/scripts/ts/queryStream.ts#L1369), [`workbenchViews.ts`](../../tools/workbench/src/main/webapp/scripts/ts/workbenchViews.ts#L1860).

Query explanation is conditional on `queryFeatures`: formats Text/DOT/JSON; levels Unoptimized/Optimized/Executed/Telemetry/Timed; Config disclosure for Normal/Heatmap, hotspot legend, property count, All/None and visible-property choices; Copy, Explain again, Cancel, Download explanation, Compare. Compare additionally has its own query editor, close control, Copy/Swap/Refresh explanations/Cancel/Diff, sidebar navigation toggle, and modal close. Long text/JSON/DOT/explanation data and loading/stale/error states must be measured. Main source is `workbenchViews.ts:1645-1841,1860-2014`; feature-dependent visibility means explicitly record skipped cases when server config disables them.

## Initial source candidates and their resolution

1. **Create advanced geometry:** optional rows now move through per-field wrappers and create actions are siblings of the table. Natural content width and flex wrapping explain content-driven expansion, which is intentional. Check cache/slow-query label associations and file path/Persist/Sync line co-location with rendered geometry; do not force unrelated controls to equal widths.
2. **Composite action inset:** baseline 12 px outer padding plus nested native padding was confirmed as S5. One owner now provides the inset; compact controls and visible text/glyph geometry retain dedicated regressions.
3. **Button row spacing:** baseline global 8 px native margin compounded parent gaps, confirmed as S2. Parents now own related 8 px spacing and children have 0 margins; final component edge measurements are separate from source declarations.
4. **Native-vs-shared disclosure:** `<details class=workbench-options>` and custom `.workbench-disclosure` share concepts but have different trigger padding, body insets, panel borders, and responsive behavior. Same-page details, embedded result panels, and query detail panels need comparison; keep intentional indentation intact.
5. **Control heights/cascade:** standard 36/44 px rows coexist with intentional 46 px decorated wrappers and compact native glyphs. S13's permanent RED precedes its shared logical-row correction. The renderer preserves those distinct hit/body/glyph roles rather than forcing every visual box to one size.
6. **Form shells and mobile tables:** direct-child islands and nested result surfaces have distinct intentional shell insets. Remove/Clear's accidental mobile field/label/action distances were measured in S1/S3/S4 and corrected through shared 4/12/12 px flow roles. The finite gate then reproduced an implicit-grid containment regression; a definite minimum-zero cell track is required for narrow native control widths.
