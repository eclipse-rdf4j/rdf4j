The concept abbreviates the populated result heading as `Query Result (3)`; the final live heading is `Query Result (1–3 of 3)`, intentionally restoring the existing page-range indicator and preserving pagination semantics. Add Source, Information, and Saved Queries retain their workflow labels. The intentional header copy diff is `Repository [Change]` → `Repository Change` (and the same for Server/User): keep the link text capitalized as `Change`, remove the literal square brackets, and use the locked slate link color. Server and repository header values differ only because the review fixtures differ: the concept shows `http://127.0.0.1:8081/rdf4j-server` and `Query refresh layout test (query-refresh-layout)`; the live fixture shows `http://127.0.0.1:8080/rdf4j-server` and `Workbench preview fixture (workbench-preview-20260925)`.

## Follow-up fidelity corrections

The parent review identified five component-level mismatches in the first final render. Each was reproduced in a failing Chromium contract before the shared CSS adjustment; the five failures are retained in `../../e2e/workbench-polish-followup-red-20260925.log`, and all five focused contracts passed after the corrections in `../../e2e/workbench-polish-followup-green1-20260925.log`.

1. **Native file control sizing:** The native file input previously measured 52px on desktop and 60px on mobile because its outer padding and internal selector button each added vertical space. The shared file-control variant now aligns the full chooser with adjacent controls at 36px and 44px, with a 34px/42px inner button, shared radius/weight, retained `content` field name and keyboard/native file selection.
2. **Disclosure utility typography:** Query Save/Options previously computed 14px/400 weight with an 8px radius and 37px height. Query and embedded-result utility disclosures now share 13px semibold text, 8px icon gap, 7px control radius, and the 36px desktop action height. Section disclosures preserve their separate 10px container surface.
3. **Saved metadata rules:** The XSL emits eight alternating label/value cells in one table row, so a last-table-row selector removed every separator. Cell-pair rules now draw a fine horizontal border across the first three visible label/value pairs and leave the final pair unbordered; the browser contract inspects each cell at mobile width.
4. **Technical code font:** The query editor previously computed a generic monospace stack that rendered as Courier on the review host. Query, update, saved code, explanation, and diff surfaces now use the shared `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` token at 14px desktop and 13px narrow widths.
5. **Embedded result canvas strip:** A short tuple result's body ended 12px above the 173px iframe, exposing the root canvas as a gray strip below paging. The embedded document now gives its white body a viewport minimum height; overflow and content remain visible. The browser contract confirms a white document canvas, no short-result overflow, and body coverage of the iframe.
6. **Embedded paging heading:** The tuple paging script attempted to update the embedded title through `#title_heading`, while the new result toolbar rendered an un-id'd `h2`. A focused Surefire and Chromium regression failed before the fix; the result heading now keeps that id, preserving page-range updates and eliminating the `tuple.js` null-`innerHTML` error.

The final route sweep covers all 19 route entries at desktop and phone widths, representative 320px/768px states, all 18 repository creation forms at 1440px/390px, and query disclosures, result options, Explain, Compare/Diff, fullscreen, ASK, graph, empty, invalid-result, and embedded paging states. See `route-audit-20260925-final-review/final-route-audit.md` and its JSON manifest for field/default and geometry records. The separate supplemental manifest records the five-statement isolated fixture and populated Explore/Namespaces/Export views; the long-result manifest confirms visible paging and a closed options disclosure at 1440x1200. I compared field name/type/id signatures against the previous 18-type capture: no form fields were lost; the Federation form lists one extra `memberID` checkbox because this preview currently has a third registered repository. The raw `/info` endpoint remains machine-readable output, not a Workbench page; its long payload measures 587px at the 390px viewport and is recorded without clipping or hiding data. The intentionally missing-repository route returns HTTP 500 with an error body.
