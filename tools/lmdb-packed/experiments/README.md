# Source-level C2 experiments

Every numbered patch is a cumulative production-only diff against
`lmdb-general-performance-source.zip`. They are independent alternatives, not steps
to apply on top of one another. Final sources and tests are outside this directory.

| Variant | Change | Disposition |
|---|---|---|
| 01-word-packing | Register accumulator and bounded final bytes replace bit-at-a-time writes. | Core retained. |
| 02-independent-reads | Add heap word reads and byte-array-view VarHandle; attempt independent per-lane native word loads. | Heap changes retained; native reader rejected. C2 unrolled it into many variable shifts and temporaries rather than the desired simple kernel. |
| 03-narrow-groups | Read eight narrow values together using a variable-width body; remove duplicate native payload clearing. | Generic body rejected because of register pressure and variable shifts; eliminating redundant clearing retained. |
| 04-width-specialization | Specialize a three-bit reader with fixed lane shifts. | Demonstrated the useful direction, then generalized carefully. |
| 05-narrow-specializations | Specialize widths one through eight, selected inside the existing FOR readers; include overflow and output-region guards. | Promising but wider-path and mixed-profile tradeoffs remained. Early five-fork and pinned data correspond to this variant, not to final production. |
| 06-header-dispatch | Select narrow kernels at the already-decoded block header; require at least eight requested lanes; restore original wider FOR reader bodies. | Rejected after longer warmup exposed a mixed-slice regression. Both short and sustained results are retained. |

| 07-conservative-native | Keep word packing, heap word reads, clearing removal and guards; restore native decode and copy bodies completely. | Released candidate. `final-results` and final verification use this source. |

See the actual filenames in this directory for the patch names. Constant-width
bodies were generated by the independently authored `../generate_narrow.py`.
All patches contain full-width exact comparisons/decoding; no approximate identity,
changed encoding, or extra per-record structure is substituted. The released native reader is unchanged for all widths and modes. The rejected native shortcut applies to FOR widths one through eight only.

The final report preserves regressions and controls. Merely producing fewer source
lines, or smaller assembly, was not an acceptance criterion. No source change is
silently renamed after a measurement; build manifests carry production hashes.
