# Workbench redesign: packaged-app screenshots

These captures show the redesigned Workbench running from the packaged Spring Boot application with a small local example repository. They are screenshots of the application, not generated design mockups. The original RDF4J logo asset is used unchanged.

The desktop captures show the main interaction states in light and dark themes. The mobile captures use a 390-pixel viewport and focus on the query editor, attached options panel, and visible results. Query execution, Explain output, result rows, and repository forms were rendered from the running application.
